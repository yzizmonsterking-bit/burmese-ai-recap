# Burmese AI Movie Recap

A lightweight static web app that generates a short movie recap based on a movie title. The app is designed for a simple, polished experience and works without a backend.

## Features
- Search for a movie title
- Generate a quick recap from a built-in movie database
- View a short summary, genre, runtime, and key moments
- Responsive, modern UI

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
